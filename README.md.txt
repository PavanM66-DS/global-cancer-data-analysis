# Global Cancer Data Analysis

## Project Overview
This project explores cancer patient records from 2015–2024 using Python and Power BI. It includes exploratory data analysis, data cleaning, and a three-page interactive dashboard.

## Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Power BI
- Power Query and DAX

## Dashboard Pages
1. **Global Cancer Overview** — patient records, average treatment cost, age, survival years, and cancer type distribution.
2. **Risk Factors and Severity** — recorded risk factors, severity scores, and cancer stage patterns.
3. **Treatment Cost and Survival** — treatment costs and recorded survival years across selected groups.

## Workflow
1. Inspect and clean the dataset using Python.
2. Perform exploratory data analysis.
3. Import the cleaned data into Power BI.
4. Create calculated columns, measures, and interactive visuals.
5. Summarize patterns observed in the dataset.

## Important Limitation
The analysis describes patterns in the available patient records. These records should not be interpreted as verified global cancer incidence, mortality, or clinical survival statistics. Observed associations do not establish causation.
